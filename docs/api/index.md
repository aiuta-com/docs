## Which AIUTA API to use

AIUTA offers three fashion AI APIs. Use the Virtual Try-On API to generate images of shoppers wearing products from your catalog. Use the Studio API to create on-model and flat-lay product imagery as part of Content Production. Explore the Unified API for supported capabilities through a shared interface. Compare the available operations with your requirements before choosing your integration.

## Compare the three APIs

Compare the intended use, inputs and outputs below. Follow each reference for supported operations and request requirements.

| API | What it returns | What you send | Reference |
| --- | --- | --- | --- |
| [Virtual Try-On API](/api/try-on/index.md) | An image of a garment worn by a person | An image of the person and a product identifier from your catalog | [Try-On reference](/api/try-on/reference.md) |
| [Studio API](/api/studio/index.md) | On-model and flat-lay product imagery | Product images you upload or serve, with the output settings | [Studio reference](/api/studio/reference.md) |
| [Unified API](/api/unified/index.md) | Supported capabilities through one entry point | See the reference for the current scope | [Unified reference](/api/unified/reference.md) |

## What each API takes in and returns

### Try-on for a shopper

Provide a person image, uploaded or selected from the predefined models, and a product identifier configured in your catalog. The API returns a generated image showing the person wearing the item. See the [try-on workflow](/api/try-on/workflow.md) for image preparation and request steps.

### Imagery for a catalog

Provide product images and output settings to generate on-model or flat-lay imagery. The Studio API gives development teams access to Content Production capabilities; consult its [workflow](/api/studio/workflow.md) and [reference](/api/studio/reference.md) for supported inputs and settings.

### One entry point

Explore the [Unified API reference](/api/unified/reference.md) to see which operations are available through its shared interface. Confirm that it supports the capabilities your integration requires.
